# 123ip-us 邮编对照表 (v2)

美国邮编（ZIP）→ 城市 / 县对照表，自建标准参考表，用于地址信息回填（查表补全缺失的邮编、城市名、县名）。

- **正式名**：123ip-us 邮编对照表
- **版本**：v2（2026-11-22 建成）
- **总行数**：41,692 行（含表头 41,693 行）
- **按州拆分**：`by-state/` 共 60 个文件

## 文件

- `123ip-us-zip-reference-v2.csv`：全表（41,692 行）
- `by-state/`：按州拆分的 60 个文件
- `merge_zip_reference_v2.py`：合并脚本（建表过程可复现）

## 来源（三源交叉合并）

1. HUD USPS ZIP Crosswalk 2026 Q2（ZIP-COUNTY_062026.xlsx，54,570 行）——县口径以 HUD 为主
2. Census Gazetteer——辅助
3. GeoNames——城市名备选

城市名以 HUD 的 USPS 首选城市名为准，GeoNames 备选。

## 核验

- 城市确认 40,541 行（97.3%）
- 县确认 41,156 行（98.7%）
- 469 个县冲突全部按「人口主县为准」定完，冲突清零，每行 flags 留证据

## 用途

回填参考表：地址行缺邮编 / 城市名 / 县名时，按规则查表补全（须带溯源 backfilled_fields）。回填在融合流水线合并后、发布前做（gold_backfill.py）。

## 注意

- 本表只放成品对照表，不放 HUD 原始文件（源输入不入库）。
- HUD 季度自查每月 1 日自动跑，有新版才通知。
